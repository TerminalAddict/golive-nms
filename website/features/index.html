Checks and protocols

Monitor the thing, not just the address

GoLive combines agentless polling, protocol-aware checks and agent telemetry. Checks are durably scheduled and produce retained availability and latency samples.

⌁

Availability

  • ICMP ping with latency and loss
  • HTTP and HTTPS status checks
  • Arbitrary TCP port connectivity
  • DNS response checks
  • TLS certificate-expiry checks
↔

Service-aware checks

  • SSH and SMTP banner validation
  • MariaDB and PostgreSQL port checks
  • RouterOS API and API-SSL
  • Custom service endpoints for web apps
  • Configurable polling intervals
◎

SNMP and network devices

  • SNMP v2c and SNMP v3 polling
  • Encrypted credential storage
  • Standard SNMP devices and switches
  • MikroTik RouterOS checks
  • Central or site-local polling
↳

Health semantics

  • Up, degraded, down and unknown states
  • Unmonitored services reduce health
  • Parent-child dependency suppression
  • One active incident per failure
  • Automatic recovery resolution

Portable host visibility

Static agents. Secure remote polling.

The Linux agent and site collector are statically compiled Go binaries. They do not require Python, Node, Java or a shared-library runtime.

▣

Linux inventory

  • Hostname, OS and package manager
  • Pending package updates
  • CPU, load and process count
  • Memory and swap usage
  • Root filesystem and uptime
  • Aggregate network counters
⇢

Portable packaging

  • Linux amd64 and arm64
  • DEB, RPM and APK packages
  • Portable tar.gz archive
  • systemd and OpenRC services
  • Source-based distribution support
◇

Secure enrollment

  • One-time 15-minute enrollment tokens
  • Private key generated on the host
  • CSR-based certificate issuance
  • Ongoing mutual TLS authentication
  • Identity revocation in the UI
⌂

Remote site collectors

  • Outbound-only NMS connection
  • Assignments limited to one site
  • Checks private site address space
  • Central automatic failback
  • No inbound collector firewall port
